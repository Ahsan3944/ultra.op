# UltraOP replaceable brand assets

Drop your own image files into this folder. The homepage automatically prefers the first available file for each asset name.

## Header / website logo
Use one of:
- `logo.png`
- `logo.jpg`
- `logo.jpeg`
- `logo.webp`

## Hero profile photo
Use one of:
- `profile.png`
- `profile.jpg`
- `profile.jpeg`
- `profile.webp`

You can delete the previous file and upload another supported format with the same base name. No code change is required.
