# UltraOP Asset Library

Keep approved creator assets inside the matching shelf. Avoid adding random files directly to this folder.

## Structure

- `stream-kit/` — OBS scenes, overlays, panels, alerts, stream graphics and stream photos.
- `facial-photos/` — creator portraits, close-ups, expressions and press photos.
- `wallpapers/` — desktop, mobile and social wallpapers.
- `video/` — thumbnails, end cards, title cards and reusable video graphics.
- `brand-kit/` — approved UltraOP logos, marks and exports.
- `minecraft/` — Minecraft skin files, renders and Minecraft-specific graphics.

## Preferred formats

PNG, JPG, JPEG, WEBP and SVG for images. Use clear filenames such as `ultraop-profile-front-01.jpg` or `stream-overlay-main.png`.

## Creator photo rule

Add facial photos only under `facial-photos/`. Keep the original high-resolution source when possible and use descriptive filenames.
